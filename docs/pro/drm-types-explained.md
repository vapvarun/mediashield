# Encryption and DRM

This page used to compare DRM types. MediaShield Pro no longer offers a DRM level, so there is nothing to compare.

MediaShield controls who can start playback. If you need encryption or DRM (Widevine, FairPlay), use your video host's own, such as Bunny Stream's, and keep MediaShield for access rules, the watermark and watch data on top.

See [Protection Philosophy](../free/protection-philosophy.md).
